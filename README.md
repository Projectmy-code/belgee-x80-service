# Belgee X80 — сервисный журнал PWA

## Что есть
- Учёт текущего пробега, даты начала эксплуатации и последнего ТО.
- История обслуживания: дата, пробег, работы, сервис, стоимость и заметки.
- Регламентные интервалы 15 000–150 000 км / 12–120 месяцев.
- Чек-лист по категориям из предоставленного изображения.
- Пользовательские работы по рекомендациям дилера на произвольном пробеге и/или дате, с отметкой выполнения и редактированием.
- Ориентировочные значения стоимости ТО-X80 из первой таблицы.
- Резервный экспорт и импорт JSON.
- Установка на iPhone через Safari → Поделиться → На экран Домой.
- Service Worker для кеширования оболочки приложения.

## Запуск на компьютере
PWA/service worker работают на HTTPS или localhost. Для быстрого локального теста откройте PowerShell в папке проекта и выполните:

```powershell
py -m http.server 8080
```

Если Python не установлен, можно опубликовать папку на GitHub Pages или Netlify. Затем откройте локальный URL на компьютере или HTTPS-ссылку на iPhone.

## Установка на iPhone
1. Разместите содержимое папки на HTTPS-хостинге.
2. Откройте ссылку в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
4. Запустите приложение с появившейся иконки.

## Данные и ограничения
Данные сохраняются локально в браузере на текущем устройстве. Экспортируйте резервную копию регулярно. При очистке данных Safari записи могут быть удалены. Приложение не синхронизирует данные между устройствами и не отправляет уведомления в фоне. Напоминания отображаются при открытии приложения.

Прайс и регламент перенесены по двум изображениям пользователя. Валюта прайса не определена, цены не гарантируются. Перед выполнением работ сверяйтесь с сервисной книжкой и официальным сервисом Belgee: применимость операций зависит от комплектации и условий эксплуатации.


## Публикация на GitHub Pages

1. Создайте публичный репозиторий `belgee-x80-service-log` на GitHub.
2. Загрузите **содержимое этой папки** в корень репозитория: `index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `sw.js`, `icons/`, `README.md`. Не загружайте только ZIP.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/(root)`, нажмите **Save**.
4. Дождитесь публикации. Адрес обычно будет `https://ВАШ-ЛОГИН.github.io/belgee-x80-service-log/`.
5. На iPhone откройте адрес именно в Safari → **Поделиться** → **На экран Домой** → **Добавить**.

GitHub Pages публикует содержимое репозитория публично. Записи ТО хранятся локально в браузере на устройстве; для переноса используйте экспорт JSON.
